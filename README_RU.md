# Distraction Free Recipes Rebuilt

[English](README.md) | [Русский](README_RU.md)

**Версия:** 1.0.0  
**Minecraft:** 1.21.1  
**Загрузчик:** NeoForge 21.1.x  
**Просмотрщики рецептов:** EMI и JEI

Distraction Free Recipes Rebuilt — клиентский мод для NeoForge, который делает интерфейс просмотра рецептов компактнее: список предметов и рецептов скрывается, пока поле поиска пустое. Также мод может скрывать пустую боковую панель избранного EMI вместе с фоном и кнопками заголовка.

## Возможности

- Автоматически скрывает список предметов EMI или список ингредиентов JEI, когда поле поиска пустое.
- Скрывает фон боковой панели избранного EMI и кнопки её заголовка, если список избранного пуст.
- Показывает краткую подсказку с текущей клавишей добавления в избранное EMI; она обновляется при переназначении клавиши и отключается в конфигурации.
- Оставляет поле поиска доступным, даже если список скрыт.
- Может показывать подсказку `Введите запрос`.
- Может показывать экранные кнопки `Показать рецепты` и `Скрыть рецепты`.
- Уменьшает непрозрачность фона полей поиска EMI и JEI.
- Позволяет независимо скрывать кнопки JEI Config, Bookmarks и Lookup History.
- Содержит английский и русский переводы собственного интерфейса и экрана конфигурации.
- Использует стандартную конфигурацию NeoForge; TxniLib и Forgified Fabric API не требуются.

## Совместимость

| Компонент | Версия, на которой проводилось тестирование |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.x (целевая сборка: 21.1.265) |
| EMI | 1.1.24+1.21.1+neoforge |
| JEI | 19.64.0.455 для NeoForge 1.21.1 |

EMI и JEI являются необязательными интеграциями. Установи хотя бы один просмотрщик рецептов для Minecraft 1.21.1. Версии в таблице использовались при разработке и тестировании, но **не являются ограничениями**. Метаданные мода не ограничивают версии EMI и JEI, поэтому NeoForge сможет обнаруживать и более новые, и более старые сборки. Однако совместимость не гарантируется: изменения API EMI или JEI могут потребовать обновления этого мода. REI не поддерживается.

Это клиентский мод. Устанавливать его на сервер не требуется: клиент с модом может подключаться к серверу, на котором мод отсутствует.

Файл конфигурации: `config/distraction_free_recipes-client.toml`.

## Конфигурация

Все параметры находятся в секции `[client]`:

| Параметр | По умолчанию | Описание |
|---|---:|---|
| `enabled` | `true` | Автоматически скрывать список рецептов, когда поиск пустой. |
| `hideEmptyEmiFavorites` | `true` | Скрывать боковую панель избранного EMI, её фон и кнопки заголовка, если в избранное ничего не добавлено. |
| `showEmiFavoritesHint` | `true` | Показывать подсказку с назначенной клавишей добавления в избранное EMI, пока список пуст. |
| `lowerOpacity` | `false` | Уменьшать непрозрачность фона полей поиска EMI и JEI. |
| `showHelpText` | `true` | Показывать подсказку, пока список рецептов скрыт. |
| `showToggleButton` | `true` | Показывать экранную кнопку переключения рецептов. |
| `showJeiConfigButton` | `true` | Показывать кнопку JEI Config. |
| `showJeiBookmarksButton` | `true` | Показывать кнопку JEI Bookmarks. |
| `showJeiLookupHistoryButton` | `true` | Показывать кнопку JEI Lookup History. |

Файлы переводов находятся в `assets/distraction_free_recipes/lang/`. Английский (`en_us`) используется как резервный язык; также включён русский (`ru_ru`). Отображаемый язык определяется настройками Minecraft.

## Установка

1. Установи Minecraft 1.21.1 с NeoForge 21.1.x.
2. Помести JAR мода в папку `mods` своего экземпляра игры.
3. Установи совместимую сборку EMI и/или JEI для Minecraft 1.21.1. Версии из таблицы совместимости использовались при разработке и тестировании, но не являются обязательными.
4. Запусти игру и при необходимости измени параметры в клиентской конфигурации мода.

## Сборка из исходников

Требуется JDK 21. В проект включён `gradlew.bat`: он автоматически скачивает закреплённую версию Gradle 9.2.1 и проверяет SHA-256 архива. Отдельно устанавливать Gradle в Windows не требуется.

В PowerShell выполни:

```powershell
.\gradlew.bat clean build
```

Либо запусти `build.bat` из командной строки. Готовый файл появится здесь: `build/libs/DistractionFreeRecipes-Rebuilt-neoforge-1.21.1-1.0.0.jar`.

EMI и JEI используются только при компиляции и в среде разработки. В итоговый JAR они не включаются.
